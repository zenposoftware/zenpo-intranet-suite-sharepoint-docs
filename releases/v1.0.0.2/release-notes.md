# Release Notes: v1.0.0.2

**Date:** October 15, 2026

## What's new and improved

- **Zenpo Org Chart** finds the reporting lines in a list you imported from a CSV or Excel
  file. Import the file with SharePoint's "From Excel or CSV", point the web part at the list,
  and the chart draws. You no longer pick the Person ID and Manager ID by hand. This covers
  lists where SharePoint's import moved the employee IDs into the built-in Title column.
- **Zenpo Org Chart** reads column display names as well as internal names, so Name and Job
  title map correctly on imported lists.

No other changes since v1.0.0.1.

# Release Notes: v1.0.2.0

**Date:** November 6, 2026

## What's new

- **Enterprise editions are now fully supported.** Planned from the start, the Enterprise
  edition is complete and enabled. An Enterprise package is built for one organization,
  with its name, licensed unit, SharePoint domains, user limit and license end date inside.
  It never contacts Zenpo: no registration, no license check against a Zenpo service, no
  usage reporting. It runs in GCC High, DoD and other tenants that block outside calls. Same
  web parts, same features and same solution ID as the Marketplace package, so an Enterprise
  package replaces the Marketplace one in place and existing pages keep working.
- **License shown where administrators look.** The app catalog description and the settings
  pane of every web part say whose Enterprise license it is, the domains and user limit it
  covers, and when it ends.

## What's fixed

- The free web parts in an Enterprise package no longer say they are blocked.

Nothing changes for Marketplace customers in this release.

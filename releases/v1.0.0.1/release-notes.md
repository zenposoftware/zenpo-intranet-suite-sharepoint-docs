# Release Notes: v1.0.0.1

**Date:** September 30, 2026

## What's new and improved

- **Zenpo Page Templates:** corrected an incorrect button label. On a site where the layouts
  are already installed, the button read "Install more layouts or create a Home page"; the
  wizard does not create a Home page. It now reads "Install more layouts". No other changes
  since v1.0.0.0.
